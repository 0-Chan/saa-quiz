# saa-quiz

AWS SAA 시험 대비용 로컬 문제 풀이 CLI입니다. 문제 번들에서 불러온 SAA-C03 객관식 문제를 풀고, 답과 함께 **확신도**를 고르면 확신도 기반 채점(CBM) 규칙으로 XP를 받습니다. LLM은 쓰지 않고, 모든 기록은 로컬 md 파일로 남습니다.

## 설치
```bash
npm install -g saa-quiz   # 이후 어디서든 `saa` 명령 사용
```
Node.js 20.12 이상이 필요합니다.

## 사용법
| 명령 | 설명 |
|---|---|
| `saa quiz` | 문제를 풉니다. 처음 실행할 때 문제 폴더가 비어 있으면 기본 문제를 자동으로 불러옵니다(아래 "기본 문제"). 순서는 안 푼 문제 → 마지막에 틀린 문제 → 오래전에 푼 문제입니다. 오답노트에 문제가 있으면 먼저 풀지 묻습니다. 답을 고르고 확신도를 선택하면 결과와 XP가 표시됩니다. Ctrl+C를 누르면 그때까지 저장된 기록만 남기고 종료합니다. |
| `saa xp` | XP, 진도(푼 문제, 맞은 문제, 정답률과 합격선 72% 충족 여부), 풀이 시간, 오답노트, 약점(약한 서비스·도메인별 정답률), 파일 경로를 묶음별로 보여줍니다. 정답률은 문제마다 마지막 시도 기준입니다. |

## 기본 문제
이 저장소에는 문제 데이터가 들어 있지 않습니다. 처음 `saa quiz`를 실행하면 **접근 코드**를 묻습니다. 코드를 입력하면 기본 문제를 한 번 받아 오고 바로 퀴즈가 시작됩니다.

```
◆  접근 코드
│  xxx-xxx                    ← 관리자에게 받은 코드
◆  기본 문제 674개를 불러왔습니다.
```
- 코드는 관리자에게 직접 받으세요. 3번 틀리면 종료되고, 다시 실행하면 또 물어봅니다.
- 문제가 하나라도 있으면 다시 묻지 않습니다. 처음부터 다시 받고 싶으면 `questions/` 폴더를 비우세요(풀이 기록도 함께 지워집니다).
- 오프라인이거나 번들 파일을 직접 가지고 있으면 `SAA_SEED_FILE=/path/to/seed.json saa quiz`로 코드 없이 불러올 수 있습니다.

### 관리자용: 코드 서버
코드 확인은 Lambda 함수(`infra/seed-gate`)가 합니다. 코드가 맞으면 비공개 S3 버킷의 번들을 돌려주고, 틀리면 1초 뒤 403을 돌려줍니다.
```bash
SAA_SEED_BUCKET=<버킷> scripts/deploy-gate.sh   # 함수·권한·Function URL 생성/갱신, URL 출력 → src/meta.ts의 SEED_GATE_URL
scripts/set-code.sh                             # 새 무작위 코드 발급(교체). 이전 코드는 즉시 무효
scripts/set-code.sh my-own-code-phrase          # 직접 정하기
```
- 코드는 해시만 Lambda 환경변수에 저장되고 화면에만 한 번 출력됩니다. **코드를 저장소나 공개된 곳에 적지 마세요.** 짐작하기 쉬운 코드(시험 코드 등)는 쓰지 마세요.
- 번들 형식: `{"questions": [{"id", "stem", "options": {"A": …}}], "answers": [{"id", "answer": ["B"], "confidence": "high|medium|low", "rationale_ko", "services": ["S3"], "domain": "secure|resilient|performance|cost"}]}`. 확신도 `low`는 건너뜁니다. `services`와 `domain`은 없어도 됩니다.

## XP 규칙 (CBM)
| 확신도 | 정답 | 오답 |
|---|---|---|
| 확실 | +3 | −2 |
| 애매 | +2 | −1 |
| 자신 없음 | +1 | 0 |

- 복수 정답 문제는 정답을 모두 정확히 골라야 정답입니다.
- 같은 문제는 하루(로컬 날짜)에 첫 시도만 XP에 반영됩니다. 그 뒤의 시도도 기록은 됩니다.
- 누적 XP가 10, 30, 60, 100, 150, … (5n(n+1))에 도달하면 터미널에 콘페티가 1초쯤 터집니다.
- 누적 XP가 −10, −30, −60, …까지 떨어지면 0점으로 리셋할지 묻습니다. 점수마다 처음 한 번만 묻습니다.
- XP는 따로 저장하지 않고, 매번 문제 파일의 시도 기록에서 다시 계산합니다. 누적 XP는 음수가 될 수 있습니다.

## 풀이 시간
- 선택지를 본 순간부터 답을 고를 때까지의 시간입니다. 문제마다 결과 줄에 `정답입니다! 1분 12초만에 선택: B`처럼 표시되고, 시험 기준(문항당 2분, 65문항/130분)을 넘으면 함께 알려 줍니다.
- 세션이 끝나면 풀이 시간 합계와 문제당 평균을, `saa xp`에서는 오늘·누적 풀이 시간을 보여줍니다.
- 화면을 띄워 두고 자리를 비운 경우를 대비해 한 문제는 최대 10분으로 셉니다.

## 오답노트
- 틀린 문제는 오답노트에 모입니다. 틀린 뒤 **다른 날** 맞히면 졸업하고, 다시 틀리면 다시 들어옵니다(같은 날 바로 다시 맞힌 건 치지 않습니다).
- "확실"을 골랐는데 틀린 문제는 **확실인데 틀림**(잘못 알고 있는 개념), 나머지는 **몰라서 틀림**으로 나눕니다.
- `saa quiz`를 시작할 때 오답노트에 문제가 있으면 먼저 풀지 묻습니다. 먼저 풀면 확실인데 틀림 → 몰라서 틀림 순서로 내고, 다 풀면 평소 순서로 이어집니다.
- 데이터 폴더의 `wrong-notes.md`에 서비스별 요약과 문제별 지문·선택지·내가 고른 답 이력·정답·해설이 정리됩니다. 풀 때마다 다시 만들어지므로 직접 고치지 마세요.
- 문제에 서비스·도메인 태그가 있으면 `saa xp`에 약한 서비스와 도메인별 정답률이 나옵니다. 태그는 0.3.0 이후 처음 문제를 받을 때 들어옵니다.

## 데이터
- 위치는 `$SAA_DATA_DIR`이고, 없으면 `~/saa-quiz`를 씁니다. 문제는 `questions/<id>.md`에 하나씩 저장됩니다.
- frontmatter에 `id`, `createdAt`, `choices`, `answer`, (태그가 있으면) `services`, `domain`, `attempts`가 있고, 본문에 `## 문제`와 `## 해설`이 있습니다. 직접 편집해도 됩니다. 형식이 깨진 파일은 경고 한 줄을 보여주고 건너뜁니다.
- XP 리셋 기록은 데이터 폴더의 `xp-resets.md`에 남습니다(물어본 점수, 리셋 때 더한 XP).
- `id`는 지문, 선택지, 정답의 해시(sha256 앞 8자리)입니다.

## 개발
```bash
npm install && npm run build && npm link          # 소스에서 `saa` 명령 설치
npm run dev -- quiz                               # tsx로 바로 실행
npm run typecheck && npm test                     # 작업을 끝내기 전 게이트
SAA_DATA_DIR=$(mktemp -d) npm run dev -- quiz     # 실제 데이터와 격리해서 테스트 (접근 코드 입력)
```
규칙과 명세는 `AGENTS.md`, v0.1 구현 계획은 `docs/plans/saa-quiz-v0.1.md`에 있습니다.
